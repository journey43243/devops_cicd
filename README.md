# CI/CD конвейер для микросервисов с использованием Jenkins и Docker

## Описание проекта

Я построил CI/CD конвейер для микросервисов, используя Jenkins и Docker, разделив приложение на фронтенд и бэкенд сервисы. Этот проект помог мне улучшить навыки работы с Git, GitHub, Jenkins и Docker за счет интеграции непрерывного тестирования, версионирования и развертывания.

## Результат

Я успешно:

- Инициализировал Git и GitHub репозиторий.
- Создал CI/CD конвейер с Jenkins.
- Контейнеризировал микросервисы для развертывания.
- Связал GitHub с Jenkins для автоматизации.
- Получил базовое понимание создания API и их связи с фронтендом.
- Обрел уверенность в практиках DevOps.

Этот проект дал мне необходимые навыки и опыт, которые будут ценны для реальной работы в среде DevOps и разработки программного обеспечения.

### Рабочий процесс

1. Настройка Git и GitHub.
2. Создание фронтенда на HTML, CSS и JavaScript.
3. Создание Node.js API, возвращающего JSON, и связь его с фронтендом.
4. Контейнеризация приложения с помощью Docker.
5. Локальное тестирование: доступ к фронтенду через `localhost`, а к API через `localhost:3000/data`.
6. Автоматизация всего процесса с помощью Jenkins.

## 2. Инструменты и технологии

Для этого проекта я использовал следующие инструменты и технологии:

- **Jenkins**: Для автоматизации CI/CD конвейера.
- **Docker**: Для контейнеризации приложения и управления микросервисами.
- **Git**: Для контроля версий и управления репозиторием.
- **GitHub**: Для хостинга исходного кода и Jenkins конвейера.
- **Node.js**: Для бэкенд микросервиса.
- **HTML/CSS/JavaScript**: Для фронтенд микросервиса.
- **Python `unittest`**: Для автоматического тестирования бэкенд микросервиса.

## 3. Установка и настройка

Выполните следующие шаги для установки необходимых инструментов:

### Установка Jenkins

1. Скачайте Jenkins с [официального сайта Jenkins](https://www.jenkins.io/download/).
2. Запустите установщик и следуйте инструкциям на экране для завершения установки.
3. Откройте Jenkins в веб-браузере по адресу `http://localhost:8080` и следуйте инструкциям для получения первоначального пароля администратора.

![image](https://github.com/user-attachments/assets/d72069b7-260f-4b67-a1b6-22a602c675d0)

### Установка Docker

1. Скачайте Docker Desktop с [сайта Docker](https://www.docker.com/products/docker-desktop).
2. Запустите установщик и следуйте инструкциям для завершения установки.
3. После установки откройте Docker Desktop и убедитесь, что он работает.
4. В конце этого документа я описал возникшие проблемы и их возможные решения.

![image](https://github.com/user-attachments/assets/32d1de70-0f5f-4aae-85a9-fac1ced91904)

### Установка необходимых плагинов Jenkins

1. Откройте Jenkins в веб-браузере.
2. Перейдите в **Manage Jenkins** > **Manage Plugins**.
3. На вкладке **Available** найдите и установите следующие плагины:
   - **Docker Pipeline**
   - **Git**
   - **Pipeline**
4. После установки перезапустите Jenkins, чтобы плагины загрузились.

![image](https://github.com/user-attachments/assets/d72efb2a-451e-4bbc-9f48-1787b6aa0ad0)
